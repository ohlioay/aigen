# 기획서 템플릿

1단계에서 이 구조로 기획서를 작성한다. 사용자가 읽고 고르는 문서이므로, 표는 그대로 살리고
추천안에는 ✅를 붙인다. 추천 이유를 한 줄로 적지 않으면 사용자가 판단할 근거가 없다.

## 작성할 때 주의할 점

**추천은 제품에 맞춰 바꾼다.** 위 표의 ✅는 예시 기본값이지 고정이 아니다. 방한 패딩이면 웜
골든아워가 맞지만, 여름 쿨링 조끼면 쿨 시네마틱이 맞다. 제품 설명을 읽고 매번 다시 판단한다.

**용도를 물어보면 추천이 정확해진다.** 상세페이지용인지 SNS 광고용인지에 따라 비율도 그레이딩도
달라진다. 사용자가 말하지 않았고 기획이 갈릴 것 같으면 기획서를 내기 전에 한 번 묻는다.

**샷 리스트의 시간 배분은 균등하게 하지 않는다.** 3초는 동작 하나를 담기에 충분하지만 감정의
전환이나 리빌에는 모자란다. 히어로 샷에 시간을 몰아주고 인서트를 짧게 가져가는 편이 낫다.
